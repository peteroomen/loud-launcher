# Live system contract

Package `io.github.peteroomen.loud.system`. Construct `SystemRepository(context)` once in the ViewModel, `lifecycle.addObserver(repository)` in Activity, `repository.close()` in ViewModel.onCleared. Implements DefaultLifecycleObserver and Closeable. Compose collects with collectAsStateWithLifecycle. Every resume refreshes permission switches; foreground observers stop with Activity.

StateFlow properties:
- `clock: ClockState(now: Instant, zone: ZoneId, nextAlarm: Instant?)`.
- `battery: BatteryState(levelPercent: Int?, charging: Boolean)`. null level means unavailable; do not label as on battery then.
- `weather: WeatherState(place: WeatherPlace, reading: WeatherReading?, lastUpdated: Instant?, loading: Boolean, offline: Boolean, error: String?)`. WeatherPlace(name, latitude, longitude, country="", timezone="auto", usesLocation=false); default Hamilton NZ (-37.787,175.279). WeatherReading(temperatureC:Double,weatherCode:Int).
- `calendar: CalendarState(month: YearMonth, events: List<CalendarEvent>, permissionGranted:Boolean, loading:Boolean, error:String?)`. CalendarEvent(id:Long,title:String,start:Instant,end:Instant,allDay:Boolean,calendarName:String). Queries provider-expanded recurrence/visible calendars, chronological selected month agenda. Query range is union of UTC and device month bounds; timed events overlap local month, all-day events overlap UTC month. Render all-day dates in UTC; timed dates in device zone.
- `notifications: NotificationState(connected:Boolean,counts:Map<String,Int>)` with computed `total`. Active badge-eligible clearable notifications, not guaranteed unread messages; group summaries excluded. Grant can be true while service is connecting: distinguish permissions.notificationAccess from notifications.connected. Notification content stays transient and is never retained/persisted.
- `media: NowPlaying?` (title,artist,art:Bitmap?,playing,packageName,durationMs,positionMs,positionAt,speed), `positionNow()`. Event-driven sessions watch all active players, prioritize newest playing session, retain paused selection. Local bitmap/content/resource art only; no remote artwork requests.
- `usage: UsageState(permissionGranted:Boolean,entries:List<AppUsage>,error:String?)`. AppUsage(packageName,foregroundMs,lastUsed:Instant). 7-day actual device foreground time. UI/core uses launcher-count fallback when denied/empty and labels fallback honestly.
- `permissions: PermissionState(calendar,notificationAccess,usageAccess,coarseLocation,powerBubbleAvailable)` booleans.

Methods: `refresh()`, `setCalendarMonth(YearMonth)`, `refreshWeather(force:Boolean=false)`, `suspend searchWeatherPlaces(query:String):List<WeatherPlace>` (trimmed fewer than2 chars gives empty; errors propagate), `selectWeatherPlace(WeatherPlace)`, `useCoarseLocation():Boolean`, `togglePlayPause()`, `skipNext()`, `skipPrevious()`, `openPlayer():Boolean`, `close()`.

Optional coarse location is a single foreground request on explicit user action; no tracking. false means permission/provider unavailable; accepted request may return no fix (reported in weather.error). Revoking location resets location-derived configuration to Hamilton before foreground/background network requests. Calendar/usage protected state clears on permission revoke; calendar observer reattaches after a runtime prompt even if Activity only paused.

SystemActions Boolean helpers: start(context,intent), openAlarms(context), openCalendar(context,at:Instant=Instant.now()), openCalendarEvent(context,event), openApp(context,packageName), openWeb(context,url), webSearch(context,query), screenOff(context), expandNotifications(context), openNotificationSettings(context), openUsageSettings(context), openAppSettings(context), powerBubbleAvailable(context). false means rejected/no capable app, not success. installedDeveloperApps(context):List<DeveloperApp(packageName,label)> discovers installed launchable Claude com.anthropic.claude, ChatGPT com.openai.chatgpt, GitHub com.github.android. Vercel uses web https://vercel.com (no assumed native package). Fallback URLs: https://claude.ai, https://chatgpt.com, https://github.com.

Power Bubble public actions `io.github.peteroomen.powerbubble.action.SCREEN_OFF` and `.NOTIFICATIONS`, package io.github.peteroomen.powerbubble. No new accessibility service or hidden status-bar reflection.

Manifest: INTERNET, ACCESS_NETWORK_STATE, READ_CALENDAR, ACCESS_COARSE_LOCATION, PACKAGE_USAGE_STATS (tools:ignore="ProtectedPermissions"). Register `.system.LoudNotificationListener` exported=true with permission android.permission.BIND_NOTIFICATION_LISTENER_SERVICE and intent action android.service.notification.NotificationListenerService. No custom receiver (foreground dynamic system receivers only). queries MAIN/LAUNCHER, SHOW_ALARMS, VIEW content/https, WEB_SEARCH, Power Bubble both actions/package. Dependencies androidx.work:work-runtime-ktx:2.10.1, androidx.lifecycle:lifecycle-common:2.9.2, org.jetbrains.kotlinx:kotlinx-coroutines-android:1.10.2, androidx.core:core-ktx:1.16.0. WorkManager merged manifest initialization is sufficient.

Only Open-Meteo weather/geocoding network initially. SharedPreferences weather cache, last-success timestamp, honest loading/error/offline state, no sample fallback. Unique periodic WorkManager45min with network constraint; actual OS timing varies. Automatic checks rate limited30min including failed attempts; explicit user refresh can override. City changes discard old-city in-flight results. Worker reports failure if forecast/cache inaccessible.
