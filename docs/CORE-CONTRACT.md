# Loud core contract

Create one `data.LoudRepositories(context)` application instance; `.close()` disposes it. Exposes `.apps: AppRepository`, `.icons: IconCache`, `.settings: SettingsRepository`, `.layout: LayoutRepository`, `.initializationError: StateFlow<String?>`, suspend `.exportBackup(): String`, `.importBackup(json): Result<Unit>`, `.reset()`, `.openWebsite(url,title=""): Result<Unit>`.

`data.AppEntry(id,label,packageName,component: ComponentName,user: UserHandle,profileSerial: Long,installedAt: Long)` IDs are profile-serial + flattened component. `.searchApp()` converts to pure model `SearchApp`. `data.AppShortcut(id,label)`.

AppRepository: `.apps`, `.loading`, `.error` StateFlows; `.refresh()`, `.launch(app,fromSearch=false): Result<Unit>`, `.openAppInfo(app): Result<Unit>`, `.uninstall(app): Result<Unit>`, suspend `.shortcuts(app): List<AppShortcut>`, `.launchShortcut(app,id): Result<Unit>`. IconCache suspend `.load(app,sizePx): Bitmap?` is off main thread; `.cached(id,sizePx)`, `.clear()`.

SettingsRepository `.settings: StateFlow<model.LauncherSettings>`; suspend `.update(transform)`, `.hideApp(id,hidden)`, `.renameApp(id,name: String?)`. Settings: palette String (Taxi/Riso/Acid/Night Brutal/Candy), shape AppearanceShape (Square/Round, default Round), gridColumns 2..4 (default4), haptics/decorations Boolean, wallpaperUri nullable content URI, appPreferences AppPreferences(hiddenIds Set,renames Map). `.displayName(id,fallback)` resolves rename.

LayoutRepository `.tiles: StateFlow<List<HomeTile>>`, `.history: StateFlow<Map<String,LaunchStats>>`, `.webHistory: StateFlow<List<WebVisit>>`, `.loaded: StateFlow<Boolean>` (wait before widget reconciliation). Suspend `.add(tile)`, `.update(tile)`, `.remove(id)`, `.reorder(ids)` exact permutation, `.recordLaunch(id,fromSearch=false)`, `.recordWebsite(url,title="")`.

HomeTile(id UUID default,kind HomeTileKind,columns=4,rows=1,color: Long?=null,config: Map<String,String>=emptyMap). Kind names: Clock, Weather, Calendar, Music, Frequent, Web, Dev, App, Notifications, Note, Battery, Focus, Habit, Widget. Span 1..4; color unsigned ARGB. App config appId; Web url/title; Dev urls newline-separated HTTPS; Note text; Focus minutes/deadline (epoch ms,0 paused)/remainingSeconds; Habit text/checked; Weather city/latitude/longitude; Widget widgetId/provider/profileSerial/title.

AppSearch.rank(apps List<SearchApp>,query,preferences,history=emptyMap(),now=...) matches rename/prefix/tokens/substring/acronym/subsequence/typos, hides hidden apps until trimmed query >=2 characters. Empty query stays A–Z. `.suggestions(apps,preferences,history,pinnedIds=emptyList(),now=...,limit=8)` uses launcher frecency and pinned fallback; excludes hidden/missing. LaunchStats(count,searchCount,lastOpened). WebVisit(url,title,count,lastOpened) records only launcher-opened URLs, max200.

BackupCodec version1 validates complete bounded JSON before writes (duplicate IDs, illegal spans/colors/config, unsafe URL schemes/credentials/token query, bad counts). Room DB replace includes settings recovery journal; Preferences DataStore failure restores previous DB; startup finishes interrupted settings commit. Shared mutex serializes changes and backups. Import drops Widget tiles (IDs belong to original host) and clears wallpaper (content grant cannot transfer). Missing app references are retained for unavailable tile UI. Backup excludes auth/session tokens. Initial note blank, no sample app content.
